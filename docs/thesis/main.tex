\addcontentsline{toc}{chapter}{Abstract}
% ONE PAGE MAX. Structure (one paragraph each):
% 1. Context: agent runtimes have shrunk (OpenClaw -> nanobot -> PicoClaw),
%    but all stop at Linux; the untested assumption is the OS itself.
% 2. What was built: MimiClaw, a complete agent runtime (~8.3k lines C)
%    on bare-metal ESP32-S3; loop, model-managed memory, skills, channels,
%    autonomy, safety guards; cloud LLM for reasoning only.
% 3. What was measured: parity with Linux runtimes on a common task set at
%    orders-of-magnitude lower footprint/energy; the within-turn quadratic
%    re-upload problem and the context-compaction ladder that removes it;
%    the skill design space without an OS; guarded speculative execution
%    cutting cloud calls by the acceptance length.
% 4. Claim: the essence of an agent runtime does not depend on an OS;
%    contributions listed in one sentence.
